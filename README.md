# IT/OT CTF Development – ERAU (AGV Component)

This repository is a **partial public copy** of a private repository for the Boeing IT/OT CTF Capstone project at Embry-Riddle Aeronautical University (ERAU). It contains **only my portion** of that project: the AGV (Automated Guided Vehicle) simulation environment. Other components of the CTF (CNC machine, CTFd deployment, business IT, VPN, etc.) are not included.

## Contents

- [`AGV/`](AGV/) – A containerized ROS Noetic + Gazebo aviation warehouse simulation with a TurtleBot3 Burger AGV, accessible in the browser via noVNC. See [`AGV/README.md`](AGV/README.md) for setup and details.
